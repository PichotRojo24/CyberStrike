# 🎮 Cyber Strike

## 🧠 Descripción
**Cyber Strike** es un juego de **combate 1v1 en 2D** con modo **local y multijugador online**, desarrollado con **Phaser 3** y **Node.js**.  

El objetivo del juego es **derribar al oponente fuera del escenario** mediante empujes, saltos, ataques y el uso estratégico del espacio.

El proyecto forma parte de la **Práctica Obligatoria – Fase 3** de la asignatura **Juegos en Red (URJC)**.

## ⚙️ Instrucciones para ejecutar el juego

### 1️⃣ Instalar dependencias
Desde la carpeta raíz del proyecto:
npm install


## Ejecutar el proyecto

El juego puede ejecutarse de dos formas:

Modo desarrollo: npm run dev
Modo servidor: npm start

## Abrir el juego en el navegador:
En la PC que ejecuta el servidor: http://localhost:8080

Para otros jugadores conectados a la misma red (modo online): http://IP_DEL_SERVIDOR:8080
Ejemplo real: http://192.168.1.130:8080/
